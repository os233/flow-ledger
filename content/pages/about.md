## 我是谁

一个相信「写下来才算想清楚」的人。这里是我公开的思考流水：灵感速记、与 AI 的对话归档、GitHub 项目动态，以及整理过的正式博客。

## 为什么是流水账

- **内容归自己**：所有内容都是本仓库 `content/` 目录下的 Markdown 文件，Git 记录每一次修改，随时可迁移、可备份。
- **先记下，再整理**：灵感速记不需要完美，等它长出上下文，再沉淀为正式文章。
- **可长期保存**：纯文本 + Git 是最长寿的内容格式。哪怕这个站点消失，内容资产依然完整。

## 使用说明

- 顶部搜索与导航可按内容类型浏览；标签页可跨类型聚合。
- 标为 `private` 的内容只存在于我的私有副本中，不会出现在线上。
- 项目卡片的数据来自 GitHub API，每日由自动化流程刷新。
