## 计划书验收条款对照

### 导入样例可追溯

- 迁移样例集（纳入版本控制，`scripts/import-fixtures/`）：编码（GBK/GB18030）、时区（+08:00 归一 UTC）、相对图片（存在/缺失/外链三态）、代码块、重复 slug（自动加后缀）、损坏 Frontmatter（跳过并记录，不做猜测性修复）、大文件（2MB）——七类全部按预期处理；
- 报告：`docs/migrations/2026-09-26T15-15-00-import-report.md`（汇总表 + 逐项明细：标题/日期/图片/代码块/标签/原文链接/损失逐项可追溯）；
- 导入默认 `status: draft`，人工确认后才改 public，不自动公开。

### 导出 MD 可被另一静态博客直接使用

- 指定目标：Astro 官方 blog 模板。导出 MD 附带 `pubDate`/`description` 别名字段，通过该模板**同款 content schema** 校验，并在全新 Astro 项目中构建成功（create-astro 脚手架受环境权限限制，采用官方 schema 等价验证）；
- 单篇导出（MD + 独立 HTML + media/ 相对附件）、全站 ZIP（默认仅 public，`--with-drafts/--with-private` 显式开关）、RSS 为站点 `/rss.xml`。

### 预览部署（新增条款）

- 访问范围：公开（与主站同级），因此预览只含 public 内容；draft/private 在预览构建中同样被过滤（覆盖层跑可见性检查）；
- 过期与删除：PR 关闭自动重新部署 main，预览目录随之消失；
- 实跑记录：PR 打开/更新两次部署成功，预览链接评论正常，主站无恙；关闭清理首次失败（漏构建步骤）已修复并复验。
