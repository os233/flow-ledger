流水账是一个基于 Astro + TypeScript 的个人数字花园，部署在 GitHub Pages 上。

- 内容即代码：所有文章、灵感与归档都是仓库内的 Markdown 文件。
- 构建即发布：合并到 `main` 后由 GitHub Actions 自动构建部署。
- 示例说明：本项目卡片的实时数据（Stars、Forks 等）通过 GitHub API 刷新缓存，这里以 Astro 框架仓库作为演示目标。
